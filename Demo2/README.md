## 硬限制：離爐一分鐘

茶壺離開電磁爐約 60 秒後糖會凝固。時間預算：

| 動作 | 秒 |
|---|---|
| 離爐、抬高、移到工作區上方 | ~5 |
| 下降到起筆高度 | ~3 |
| **實際畫圖** | **~40** |
| 抬起、離場 | ~3 |
| 回電磁爐 | ~5 |
| 緩衝 | ~5 |

所以 `shapes.py` 內建 `--limit`（預設 45 秒），超過會擋下來並告訴你要多快。

## 三種圖形

由易到難，各驗證一件事。

| 圖形 | 驗證什麼 | 尺寸 | 路徑長 | 點數 | 60 mm/s 需時 |
|---|---|---|---|---|---|
| `spiral` 螺旋 | 等速連續、曲率單調變化 | 97 × 91 mm | 920 mm | 123 | 15.3 s |
| `wave` 蛇行波浪 | 曲率換向時糖會不會積厚 | 101 × 58 mm | 483 mm | 67 | 8.0 s |
| `star` 五芒星 | 尖角必須減速，糖會不會積成一坨 | 95 × 100 mm | 486 mm | 62 | 8.1 s |

**螺旋刻意由內往外畫。** 結束時要把壺轉正斷流，壺嘴一定會滴糖。
由外往內畫會滴在正中心最顯眼處；由內往外結束在最外圈，可以順勢拉出圖外。

**每種圖形收尾都沿切線外拉 10 mm**（`--tail`），讓斷流的滴糖落在圖案之外。

五芒星是挑戰題。過不了不影響 DEMO，反而是有價值的技術限制紀錄。

## 用法

```bash
PY=.venv/bin/python

# 產生座標 + 預覽圖
$PY Demo2/shapes.py spiral -o Demo2/out/spiral.json --preview Demo2/out/spiral.png
$PY Demo2/shapes.py wave   -o Demo2/out/wave.json   --preview Demo2/out/wave.png
$PY Demo2/shapes.py star   -o Demo2/out/star.json   --preview Demo2/out/star.png
```

預覽圖上：藍圈 = 起點，橘圈 = 終點，紅點 = 實際送給手臂的座標。

常用參數：

```bash
# 螺旋加大到外徑 70、7 圈
$PY Demo2/shapes.py spiral --r1 70 --turns 7 -o Demo2/out/spiral.json

# 提高速度（糖太粗時）
$PY Demo2/shapes.py spiral --speed 90 -o Demo2/out/spiral.json
```

## 現場流程（人工加熱）

1. 茶壺鎖上 RS07L 法蘭面，裝糖，放電磁爐上加熱到融化
2. 確認畫布原點與傾角已校正（見下方「明天要做的事」）
3. 手動把壺從爐上拿起 → 手臂歸位 → 執行程式
4. 畫完離場，壺放回爐上
5. 記錄：速度、傾角、實際線寬、有沒有積糖或斷線

## 明天的三個風險

1. **壺嘴沒有明確尖點** —— TCP 校正靠「繞工具尖端旋轉、目視不飄移」。
   茶壺嘴是圓弧，要先決定出糖點是哪一點（通常是壺嘴最下緣）並做記號。
2. **一分鐘沒有緩衝** —— 校正和試畫要反覆回爐，實際節奏比想像慢。
   前幾次建議用水或糖漿試，不要一開始就用會凝固的糖。
3. **重心外伸** —— 壺鎖在法蘭面上，重心離法蘭很遠，
   雖然重量輕，但高速移動時的力矩要留意，離場速度先保守。
