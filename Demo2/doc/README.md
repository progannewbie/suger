## 一句話說明

機械手臂手上鎖著裝了融化糖漿的不鏽鋼茶壺，固定一個傾角讓糖流出，
在桌面上一筆走完螺旋、蛇行波浪、五芒星三種圖形。

## 硬限制

茶壺離開電磁爐約 60 秒糖會凝固。畫圖預算 45 秒。
三種圖形實測只需 8~15 秒，時間不是瓶頸。
