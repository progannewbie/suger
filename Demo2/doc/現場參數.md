## 1. 工作區原點 base

```
POINT right_spatula = TRANS(-50, -230, 50, 90, 40, -90)
```

| 欄位 | 值 | 意義 | 狀態 |
|---|---|---|---|
| x | −50 | 工作區中心在基座座標的 X | 待驗證 |
| y | −230 | 工作區中心在基座座標的 Y | 待驗證 |
| z | 50 | 紙面高度 | 待驗證 |
| o | 90 | 茶壺姿態 | 待驗證 |
| a | 40 | **茶壺傾角，決定出糖量** | 待驗證 |
| t | −90 | 茶壺姿態 | 待驗證 |

送給 `plan_pot.py` 的寫法：

```bash
--base -50,-230,50,90,40,-90
```

執行中也可以直接用 `base,x,y,z,o,a,t` 指令覆寫（`sugar_server.as` 第 172 行），
現場調原點不需要重跑任何程式。

### 1.1 姿態角不會讓圖案傾斜

手臂端用的是 `SHIFT(org BY vx, vy, vz)`（`sugar_server.as` 第 129 行）。
Kawasaki AS 的 `SHIFT` 在**基座座標系**平移，不是在點位自己的旋轉框架裡平移。

所以傾角 40 度只作用在茶壺本身，圖案仍平貼水平桌面，z 固定不變。

## 3. ⚠ 明天上機第一件事要確認的兩點

### 3.1 離基座太近

離基座水平距離只有 **177 ~ 283 mm**，RS07L 臂展 730 mm，這個距離非常靠近基座。

**兩個風險**

1. **內側死區**。多數 6 軸手臂在基座附近有一塊到不了的區域，
   或雖然到得了但姿態極度扭曲。若最小工作半徑大於 177 mm，五芒星直接畫不了。

2. **J1 角速度暴增**。靠近基座時，同樣的線速度需要更快的旋轉。
   螺旋內圈半徑 177 mm、外圈 283 mm，內圈需要的 J1 角速度是外圈的 1.6 倍。
   J1 一旦追不上，控制器會自動降速——**速度一掉糖就積成一坨**，
   正好是「等速連續」這個硬需求最怕的事。

**檢查方式**：查 RS07L 規格書的最小工作半徑；或手動把手臂移到
(−97.6, −270.5, 50) 與 (−2.4, −170.5, 50) 兩點，看得不得了、姿態扭不扭曲。

**若確實太近，改這一行就好**

```bash
--base -50,-400,50,90,40,-90
```

距離變成 350 ~ 450 mm，落在手臂舒適的中段。圖形檔完全不用重新產生。

### 3.2 z = 50 可能太低

這個高度很接近基座平面，手臂在畫圖時手肘可能撞到基座或桌面。

**檢查方式**：不裝糖、不裝壺，手動把手臂移到工作區四個角落，目視有無干涉。

## 6. 五芒星的原點偏移

五芒星的 Y 範圍是 −40.5 ~ +59.5，**不對稱**。
因為收尾外拉的 10 mm 尾巴從最上面的頂點往上延伸。

意思是星星的實際中心比原點**往下偏約 9.5 mm**。畫的時候紙要往上放一點。
