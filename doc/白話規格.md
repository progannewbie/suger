## 這是什麼

你打一個中文字,或給一張圖,機械手臂就用糖把它畫出來。

像夜市那種糖畫師傅拉糖絲作畫,只是換成手臂來拉。

## 整個過程分成幾關

```
你打一個「台」字
   ↓  第一關:決定要畫哪些線
      把字變成一條一條的筆劃,並且標好哪裡要粗、哪裡要細
   ↓  第二關:決定手臂要停在哪些位置
      把連續的線變成一串座標點,在不走樣的前提下點越少越好
   ↓  第三關:決定手臂怎麼走
      每個點要多快、什麼時候開糖、什麼時候抬起來
   ↓  傳給手臂
      拆成一行一行的文字指令送過去
   ↓  手臂照著動
```

每一關都會存下一個檔案,所以任何一關出問題,你都可以打開來看。

## 你會看到什麼

三張圖,各回答一個問題。

| 圖 | 回答什麼 |
|---|---|
| 第一關的預覽圖 | **畫出來長什麼樣** —— 線會不會糊在一起、形狀對不對 |
| 第二關的分佈圖 | **手臂會停在哪些位置** —— 藍色小點就是停留位置 |
| 模擬軌跡圖 | **手臂實際怎麼走** —— 顏色深的地方走得慢、線會比較粗 |

第二張圖有個判斷訣竅:**直的地方點應該很少,彎的地方點應該很密**。
如果整張圖點的間距都一樣,代表有東西沒設定好。

## 怎麼操作

打開終端機,貼上一行指令,按 Enter。

**寫字**

```
.venv/bin/python sugar_arm/text2path.py 台 --size 200 --svg out/tai.svg --preview out/tai.png
```

把 `台` 換成你要的字,把 `out/tai` 換成你要的檔名。

**畫圖**

```
cd /Users/lichanghong/Documents/義大 && .venv/bin/python sugar_arm/img2path.py 你的圖.png --width 200 --svg out/圖.svg --preview out/圖.png
```

跑完,檔案會出現在 `out` 這個資料夾裡,直接點開就能看。

## 常用的幾個調整

| 你想要 | 加這一段 |
|---|---|
| 字大一點 | `--size 250`(數字是字的高度,單位公釐) |
| 一行放兩個字 | `--cols 2` |
| 直式書寫 | `--vertical` |
| 整幅連成一筆 | `--link all` |
| 一筆一筆分開寫(像楷書) | `--link none` |
| 不要粗細變化,全部一樣粗 | `--no-brush` |
| 字距寬一點 | `--gap 0.3` |

不加任何調整的話,預設是**行書連筆加粗細變化**,也就是一個字一筆寫完。

## 粗細是怎麼做出來的

這是整個系統最違反直覺的地方。

**糖流出來的量是固定的。所以手臂走得慢,糖就堆得厚,線就粗;走得快,線就細。**

粗細完全靠速度控制,不是靠壓力。

實際的做法:
- 起筆的時候走慢一點,線比較粗,像毛筆按下去
- 中段維持平穩
- 收筆的時候加速,線變細,拉出尖尖的鋒
- 字裡面連筆的那條細絲,是全程走最快的地方

我們量過一幅真跡,最粗跟最細差 4 倍。所以粗細對比也設在 4 倍附近。
**不能設更大** —— 那代表手臂要跑到很快的速度,糖絲會斷掉。

## 為什麼要連筆

每抬一次筆,糖絲就斷一次,落下的地方會留一個小疤。

所以連筆不只是好看,是**實際需要**。

同樣寫「台灣尚勇」四個字:

| 寫法 | 抬筆幾次 |
|---|---|
| 一筆一筆分開寫 | 約 50 次 |
| 一個字連成一筆 | **3 次** |
| 整幅連成一筆 | **0 次** |

連筆之間會多出細細的牽絲,那在書法裡是行書、草書的正常特徵,不是瑕疵。

代價是牽絲會佔掉總線長的三到五成。整幅連成一筆時,畫面可能會顯得亂。

## 這個系統做不到的事

| 做不到 | 原因 |
|---|---|
| 寫出真正的行草字形 | 字形來源是端正的楷書骨架,加了連筆也只是「連筆的楷書」 |
| 畫出飛白(乾筆的斷續紋理) | 糖是連續流動的液體,不會出現乾枯的缺口 |
| 填滿大面積 | 只能畫線,大塊區域只會畫出外框 |
| 描粗筆書法的照片 | 筆劃太粗又互相接觸,抽出來的中線會糊掉 |
| 保留照片的明暗層次 | 只有線條,沒有深淺 |

## 在沒有裝置的情況下能先做什麼

四件事,都不需要糖、噴嘴或畫布:

1. **確認手臂會動、範圍夠不夠** —— 讓它在空中畫一個方框
2. **量短線段會不會拖慢速度** —— 同樣長度的直線,一次走完 vs 切成很多小段,
   用碼表比時間。這件事的結果會決定一個重要參數要設多少
3. **確認連線正常** —— 讓手臂在空中把整個字「畫」一次
4. **確認開關訊號的時機正確** —— 用示教器的畫面看訊號有沒有在對的時候切換
